Sebelum upload

  • Program yang ada di board akan tertimpa.
  • Tutup Serial Monitor di Arduino IDE dan aplikasi lain yang memakai port board. Terminal di halaman ini ditutup otomatis selama upload.
  • Jangan cabut USB atau menutup halaman ini selama upload berjalan.
  • Kalau port tidak muncul, install driver USB board (CH340 atau CP210x).
  • Kalau ESP32 gagal terhubung, tahan tombol BOOT saat upload dimulai.
